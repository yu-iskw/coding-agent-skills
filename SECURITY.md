# Security policy

## Report a vulnerability

Use the repository's [Security Advisories page](https://github.com/yu-iskw/coding-agent-skills/security/advisories) if private reporting is available. Include the affected skill or commit, the required configuration and permissions, the behavior observed, and its impact.

If private reporting is unavailable, open an issue with a brief request for private follow-up. Keep credentials, private repository data, and sensitive technical details out of the public issue.

## Running the skills

Routing files express preferences. Enforce permissions, workspace and network access, and integration policy through the host, the destination CLI, or process containment. Review the effective account, provider, sandbox, and enabled project resources before sending repository data to another agent. See the [CLI security convention](README.md#security-convention-for-cli-skills).
